### Blocking r2 item: refund hang (fixed)
- **The fix:** `SelfCrafts.knownItem(id, what)`:
  - It uses `Identifier.tryParse` and `getOptional`, and treats AIR as unknown.
  - For an unknown id it returns null with one WARN, and the caller skips that entry.
  - It is used by `SmithCrafts.refund`, `SelfCrafts.refund` and the `SelfCraftJob` leftovers loop.
  - A skipped entry is not added to `left`, so a refund-pending record never keeps it. The WARN therefore does not repeat every 100 ticks.
